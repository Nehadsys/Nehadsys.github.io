folio · 03 · work
— selected — Work & studies
01.MediReach

An offline-first multi-agent RAG medical assistant over a WHO corpus, running quantized Llama 3.2 3B via llama.cpp. Section-aware chunking took retrieval precision from 15% to 85%. Two semesters, one IEEE paper, several arguments with myself about what counts as a hallucination.

02.Quantization × Injection

A quiet suspicion I kept bumping into: a model that holds up at full precision doesn't necessarily hold up at int4. The paper tries to pin that down — twelve conditions, same prompts, different precisions, honest numbers.

03.PwnzzAI

A deliberately broken Flask app in the OWASP spirit, built as a bench to walk through the LLM Top 10 case by case. Pairs with a jailbreak classifier (Logistic Regression, 88.1%) — the kind of boring, useful baseline that keeps me honest.

04.AgentProbe

A red-team scanner for LLM agent chains — the kind of thing we badly needed the moment everyone started handing models shell access. Automates probes for tool-poisoning, indirect prompt injection through retrieved context, and data exfiltration via tool calls. Think Burp Suite for agents: open a bench, point it at a running chain, watch what leaks.

05.video2article

A pipeline that turns long technical talks into clean readable articles. Started as a selfish tool — I wanted the IBM Technology videos in a form I could reread. Claude API, FastAPI, Next.js, the usual Docker Compose dance.

06.UrduBench

An adversarial robustness benchmark for Urdu LLMs — the first serious evaluation set for how large models hold up in a non-English, non-Latin-script setting that 230M people actually use. Native-speaker-validated prompts, side-by-side with English translations, scored on robustness and refusal consistency. The English-centric safety literature has a blind spot shaped exactly like this.
